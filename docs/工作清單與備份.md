## 三、秘密設定（Secrets）清單

位置：Cloudflare →「line-voice-reminder」→「Settings」→「Variables and Secrets」
**類型一律選「Secret」**（選成 Text 會被清掉或外洩）。

| 名稱 | 內容 | 從哪裡拿 | 外洩或遺失時 |
|---|---|---|---|
| `APP_PASSWORD` | 網站登入密碼 | 您自己設定 | 直接在 Cloudflare 改成新密碼 |
| `LINE_CHANNEL_SECRET` | LINE 簽章用密鑰 | LINE Developers →「Basic settings」→ Channel secret | 按「Issue」重新發行，更新到 Cloudflare |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE 發訊息用金鑰 | LINE Developers →「Messaging API」→ Channel access token (long-lived) | 按「Reissue」重新發行，更新到 Cloudflare |
| `GEMINI_API_KEY` | Gemini 語音 AI 金鑰 | Google AI Studio → API keys | 在 AI Studio 刪除舊的、建立新的，更新到 Cloudflare |
| `OPENAI_API_KEY` | AI 圖片（付費） | platform.openai.com → API keys | 在 OpenAI 刪除舊的、建立新的，更新到 Cloudflare |

> 每次在 Cloudflare 更新 Secret 後，都要按「**Deploy**」才會生效。

## 四、一般設定值

這些寫在程式的 `wrangler.jsonc` 裡，想改的話跟 Claude 說一聲即可。

| 名稱 | 目前值 | 說明 |
|---|---|---|
| `OWNER_NAME` | `froglssh` | AI 打招呼、給家人訊息的落款 |
| `RETENTION_MINUTES` | `10080` | 已送出提醒保留多久（10080 分鐘＝7 天） |
| `GEMINI_MODEL` | `gemini-3.8-live` | 語音 AI 模型 |
| `GEMINI_VOICE` | `Kore` | AI 的聲音（可換 `Puck`、`Charon` 等） |
| `LINE_API_BASE` | `https://api.line.me` | LINE 伺服器位址（不需要改） |
| `PUBLIC_BASE_URL` | `https://line-voice-reminder.frog-cbd.workers.dev` | 排程傳圖片時，LINE 從這裡下載圖片 |
| `OPENAI_IMAGE_MODEL` | `gpt-image-2.5-flare` | AI 圖片模型（ChatGPT Images 2.5 Flare） |
| `OPENAI_IMAGE_QUALITY` | `medium` | 圖片品質：low／medium／high（越高越貴） |
| `IMAGE_DAILY_LIMIT` | `20` | 每天最多做幾張圖（控制花費） |
| `keep_vars` | `true` | 更新程式時保留後台設定 |

## 七、備份方法

### 1. 程式碼（最重要，建議每次大改後做一次）
程式碼已經存在 GitHub，本身就是備份。想在自己電腦多存一份：
1. 打開 https://github.com/froglssh/line-voice-reminder
2. 按綠色「**Code**」→「**Download ZIP**」
3. 把 ZIP 存到雲端硬碟或隨身碟，檔名加上日期，例如 `提醒小幫手_2026-09-28.zip`

### 2. 金鑰與密碼
- 記在密碼管理工具（iPhone「密碼」App、Google 密碼管理工具等），**不要**存在 ZIP、GitHub 或聊天室。
- 其實金鑰遺失也沒關係，照第三節「外洩或遺失時」重新發行即可。

### 3. 聯絡人資料（選擇性）
聯絡人的「稱呼」和「別名」存在 Cloudflare 資料庫。想備份的話：
1. Cloudflare →「Storage & Databases」→「D1」→ 點 `froglssh-reminder`
2. 點「**Console**」，輸入 `SELECT * FROM contacts;` 按執行
3. 把結果截圖存起來

> 提醒本身送出 7 天後就會刪除，通常不需要備份。另外 Cloudflare 會自動保留資料庫近期的歷史版本，萬一誤刪可以請 Claude 協助還原。

## 八、出狀況時怎麼救

| 狀況 | 原因 | 解決方法 |
|---|---|---|
| 登入頁出現「尚未設定登入密碼」 | `APP_PASSWORD` 不見了或選成 Text | 第三節，重新加一次（類型 Secret）→ Deploy |
| 忘記登入密碼 | — | 到 Cloudflare 把 `APP_PASSWORD` 改成新的 |
| 「密碼錯誤太多次」 | 連錯 5 次 | 等 15 分鐘 |
| 加好友後聯絡人沒出現 | Webhook 或 LINE 金鑰有問題 | 檢查 Webhook 網址 → 按 Verify；確認 LINE 兩把金鑰正確；然後在 LINE 傳「你好」補登記 |
| 提醒顯示「傳送失敗：LINE 金鑰錯誤」 | Access token 失效 | 重新發行 Access token → 更新 Cloudflare |
| 提醒顯示「本月免費額度已用完」 | 當月超過 200 則 | 等下個月，或升級 LINE 方案（需付費） |
| 提醒顯示「對方已封鎖」 | 對方封鎖了小幫手 | 請對方解除封鎖 |
| 按麥克風出現「尚未設定 Gemini 金鑰」 | `GEMINI_API_KEY` 不見了 | 第三節，重新加一次 |
| 「Gemini 免費額度暫時用完」 | 當天用太多 | 過一陣子再試；已建立的提醒不受影響 |
| 「沒有麥克風權限」 | 瀏覽器擋住麥克風 | iPhone：設定 → Safari → 麥克風 → 允許 |
| 整個網站打不開 | Cloudflare 更新失敗 | Cloudflare →「Deployments」看最新一筆是否失敗，截圖給 Claude |
| Cloudflare 專案被誤刪 | — | 照《設定教學》第 2、3 步重做（程式在 GitHub 不會遺失），聯絡人需重新登記 |
