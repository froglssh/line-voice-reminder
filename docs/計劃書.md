## 一、我理解的需求（重新整理版）

請先看這段，確認我沒有聽錯您的意思：

1. **這是一個只給您自己用的小工具**，不上架、不販售。
2. **電腦和手機都能打開**，畫面走「現代、極簡、有質感」的路線，正中央有一顆**圓形麥克風按鈕**。
3. **只有您能登入**。別人就算拿到網址，沒有密碼也進不來。
4. **用說的就能建立提醒**：
   - 按下麥克風 → AI 先打招呼：「嗨，froglssh，有什麼我可以幫忙的？」
   - 您說：「下週三早上十點提醒我去繳信用卡卡費」
   - AI 用說的跟您確認：「好的，我會在 10 月 7 日（星期三）早上 10:00 提醒您：繳信用卡卡費，對嗎？」
   - 您說「對」→ 提醒就建好了，畫面上的清單也會多一筆。
   - 您可以接著說下一件事，或是再按一次麥克風結束對話。
5. **時間到了，自動把提醒傳到指定對象的 LINE**，可以是您自己，也可以是家人朋友（例如小明）。
   **就算您的電腦和手機都關機，也照樣會準時送出。**
6. 送出後，清單上會標示「**已送出**」，**一週後自動刪除**。
7. AI 使用 **Google Gemini 3.8 Live**（能即時用聲音對話的 AI）。
8. **能免費就免費**。要花錢的部分會事先講清楚。

## 二、我的建議：做成「網頁版」，而且可以「加到手機主畫面」

| | 網頁版（我推薦） | App 版 |
|---|---|---|
| 電腦能用嗎 | ✅ 打開瀏覽器就能用 | ❌ 電腦要另外做一套 |
| 手機能用嗎 | ✅ 還可以「加到主畫面」，看起來和 App 一樣，會顯示您的 icon | ✅ |
| 要花錢嗎 | ✅ 免費 | ❌ iPhone 上架每年約新台幣 3,200 元；不上架的話每 7 天要重新安裝一次 |
| 更新麻煩嗎 | ✅ 我改好後，您重新整理就是新版 | ❌ 每次都要重新安裝 |

**結論**：網頁版同時滿足「電腦＋手機」、「免費」、「只有我自己用」三個條件，是最適合的選擇。
加到手機主畫面後，點開時不會有瀏覽器的網址列，使用起來就跟一般 App 一樣。

## 三、整體運作方式（白話版）

可以把這個工具想成三個角色：

```
 ┌──────────────┐     說話       ┌──────────────────┐
 │  您的手機/電腦  │ ◀───────────▶ │  Gemini 3.8 Live  │  ← 負責聽您說話、回話、整理出「提醒什麼、何時、給誰」
 │  （網頁畫面）   │               └──────────────────┘
 └──────┬───────┘
        │ 存入提醒
        ▼
 ┌─────────────────────────┐    時間到    ┌──────────────┐
 │  雲端小管家（24 小時不關機）  │ ───────────▶ │  LINE 官方帳號  │ ──▶ 您／家人的 LINE
 │  每分鐘檢查一次有沒有到期的提醒 │              └──────────────┘
 └─────────────────────────┘
```

- **網頁畫面**：您看到、按麥克風的地方。
- **雲端小管家**：放在 Cloudflare（一家大型網路公司）的免費主機上，**24 小時運作，跟您的電腦開不開機無關**。它負責記住所有提醒、每分鐘檢查一次、時間到了就叫 LINE 送出，並且每天清掉一週前已送出的提醒。
- **LINE 官方帳號**：我們會幫這個工具申請一個專屬的 LINE 帳號（例如取名「line提醒小幫手」），提醒訊息會從這個帳號發出。

### ⚠️ 一個一定要先知道的 LINE 限制

LINE **不允許任何程式用「您個人的 LINE 帳號」替您發訊息**。所以提醒訊息會由「line提醒小幫手」這個官方帳號發出，而且：

- **收訊息的人（包括您自己、小明）都必須先把這個官方帳號「加為好友」**，一次就好。
- 對方加好友後，工具會自動記下他，您在網頁上幫他取個名字（例如「小明」），之後跟 AI 說「提醒小明……」就知道要傳給誰。
- 我會做一張 **QR Code 邀請頁**，您傳給家人朋友掃一下就完成了。

訊息大概長這樣：

> ⏰ 提醒您：去蝦皮店到店取貨
> —— 來自 froglssh

### 兩個可能需要付費的情況（先跟您說，現在都不需要）

1. **Gemini 免費方案的注意事項**
   - Google 表示 Gemini 3.8 Live 在免費方案中可使用，但**每天能用多少次尚未公布**。如果哪天用到上限，AI 會暫時無法對話（已建立的提醒**不受影響**，照樣會送出）。
   - 免費方案的對話內容**可能會被 Google 用來改進產品**。提醒內容若涉及隱私（例如銀行卡號），請避免說出來。
   - 若要升級付費：大約每講 1 分鐘花費不到新台幣 1 元（聽約 $0.005 美元／分鐘、說約 $0.018 美元／分鐘）。**真的需要時我會再一步一步教您設定，並建議設定每月花費上限**。
2. **LINE 超過每月 200 則**：輕用量方案不能加購，需升級「中用量」方案（每月 800 元起）。以個人提醒來說，應該用不到。

## 五、功能清單與測試方法

每個功能都附上「**您怎麼確認它有做好**」的測試步驟。等我做完每一階段，會請您照著測試。

### 功能 1：網頁可以打開，也能加到手機主畫面
- **內容**：現代極簡風格的畫面、深色／淺色模式自動切換、使用您的 icon.png 當圖示。
- **測試方法**：
  1. 用電腦的 Chrome 打開我給您的網址，畫面正常顯示。
  2. 用手機打開同一網址 → 點「分享」→「加入主畫面」。
  3. 手機桌面出現您的 icon，點開後沒有網址列，看起來像一般 App。

### 功能 2：只有您能登入
- **內容**：輸入密碼才能進入；同一台裝置 30 天內不必重新登入；連續輸錯 5 次會暫時鎖住 15 分鐘，防止別人亂猜。
- **測試方法**：
  1. 輸入錯誤密碼 → 顯示「密碼錯誤」，進不去。
  2. 輸入正確密碼 → 進入主畫面。
  3. 用另一支沒登入過的手機（例如家人的）打開網址 → 只看到登入畫面，看不到任何提醒。
  4. 按「登出」後，重新整理 → 回到登入畫面。

### 功能 3：圓形麥克風按鈕與 AI 打招呼
- **內容**：畫面中央一顆圓形麥克風；按下後按鈕會有「呼吸光圈」動畫表示正在聽；AI 用中文說「嗨，froglssh，有什麼我可以幫忙的？」
- **測試方法**：
  1. 按下麥克風，第一次會問是否允許使用麥克風 → 按「允許」。
  2. 在 3 秒內聽到 AI 打招呼。
  3. 再按一次麥克風 → 對話結束，動畫停止。

### 功能 4：用說的建立提醒（含口頭確認）
- **內容**：AI 聽懂「什麼事、什麼時候、提醒誰」，把「下週三」「一個小時後」這種說法換算成準確的日期時間（以台灣時間為準），**先念一次給您確認**，您說「對」才建立；說「不對，改成十一點」也可以修正。
- **測試方法**（每一句都試試看）：
  1. 「下週三早上十點提醒我去繳信用卡卡費」→ AI 念出正確日期（星期三）與 10:00 → 說「對」→ 清單出現這筆。
  2. 「一個小時後提醒小明去蝦皮店到店取貨」→ AI 念出現在時間＋1 小時，對象是小明 → 說「對」→ 清單出現，對象顯示「小明」。
  3. 「明天提醒我買牛奶」（沒說幾點）→ AI 應該**反問您幾點**，而不是自己亂猜。
  4. 「提醒阿花……」（阿花還沒加好友）→ AI 應該告訴您「阿花還沒加入好友」，並詢問是否改傳給您自己。
  5. AI 確認時您說「不對，改成下午三點」→ AI 重新確認新時間。
  6. 故意說「昨天早上提醒我…」→ AI 應說明時間已過，請您重新指定。

### 功能 5：時間到自動送到 LINE（電腦關機也會送）
- **內容**：雲端小管家每分鐘檢查一次，誤差在 1 分鐘內。
- **測試方法**：
  1. 說「兩分鐘後提醒我喝水」並確認。
  2. **把網頁關掉、電腦關機、手機鎖螢幕。**
  3. 兩分鐘後，您的 LINE 收到「⏰ 提醒您：喝水」。
  4. 再試一次傳給家人（例如「三分鐘後提醒小明喝水」），請小明確認有收到。

### 功能 6：提醒清單、「已送出」標示、一週後自動刪除
- **內容**：主畫面下方列出提醒，分成「**等待中**」「**已送出**」「**傳送失敗**」三種狀態；等待中的提醒可以手動刪除（取消）。已送出的提醒 7 天後自動消失。
- **測試方法**：
  1. 功能 5 測試完後，打開網頁 → 那筆提醒顯示「已送出」與送出時間。
  2. 在「等待中」的提醒按「刪除」→ 該筆消失，時間到也**不會**送出。
  3. 自動刪除：因為要等 7 天，我會另外提供一個「測試模式」讓刪除時間縮短為 3 分鐘，方便您當場驗證；驗證完再改回 7 天。

### 功能 7：聯絡人管理（家人朋友）
- **內容**：一個「邀請好友」頁面，有 QR Code 和邀請連結；家人加入官方帳號後，會出現在聯絡人清單，您幫他取名字（小明、媽媽…），也可以設定別名（例如「老媽」＝「媽媽」）。
- **測試方法**：
  1. 用自己的 LINE 掃 QR Code 加好友 → 聯絡人清單出現一位新成員 → 取名為「我」。
  2. 請一位家人掃 QR Code → 聯絡人清單出現 → 取名「小明」。
  3. 回到功能 4 的第 2 項測試，確認 AI 認得「小明」。

### 功能 8：傳送失敗的處理
- **內容**：如果 LINE 送不出去（例如對方封鎖了官方帳號、或每月 200 則用完），會自動重試；仍失敗則標示「傳送失敗」並顯示原因，同時嘗試通知您本人。
- **測試方法**：請一位測試者先封鎖官方帳號，建立一則給他的 2 分鐘後提醒 → 清單顯示「傳送失敗：對方已封鎖」。

## 八、技術備註（給日後的維護者看，老師可以略過）

- 前端：原生 HTML/CSS/JS 的 PWA（manifest + service worker），部署於 Cloudflare Workers Static Assets。部署方式為 Cloudflare Workers Builds 連接 GitHub，推送到 main 即自動上線；D1 由 wrangler 自動建立，資料表由程式啟動時自動建立。
- 後端：Cloudflare Workers（TypeScript），資料庫 Cloudflare D1（SQLite），Cron Trigger `* * * * *` 每分鐘掃描到期提醒，另一個每日 cron 清除 `sent_at < now - 7d`。
- 語音：瀏覽器以 WebSocket 直連 Gemini Live API（model `gemini-3.8-live`），由 Worker 核發**短效 ephemeral token**，正式金鑰不落地到瀏覽器。以 function calling 定義 `create_reminder` / `list_contacts` / `cancel_reminder` 工具；system instruction 注入目前台灣時間（Asia/Taipei）與聯絡人名單，由模型解析相對時間後口頭複誦，使用者確認後才呼叫工具。後端再次驗證時間必須在未來。
- LINE：Messaging API push message；webhook 接收 `follow` 事件記錄 userId（驗證 `x-line-signature`）。
- 登入：單一使用者密碼存於 Cloudflare Secret（`APP_PASSWORD`），比對時先 SHA-256 再定時比較；session token 以雜湊存於 D1，HttpOnly + Secure + SameSite=Strict cookie（30 天）；同一 IP 15 分鐘內錯 5 次即鎖定。
- 所有時間以 UTC 儲存、以 Asia/Taipei 顯示。

## 九、需要您回覆的問題

請直接回覆題號＋答案就好（例如「1. 好」）：

1. **icon.png 找不到**：專案資料夾裡目前只有 README，沒有 icon.png，請再上傳一次。
2. **LINE 限制可以接受嗎？** 提醒會從「提醒小幫手」官方帳號發出，收件人（包含您自己）都要先加它為好友。可以嗎？官方帳號想取什麼名字？（建議：「line提醒小幫手」）
3. **訊息要不要標示是誰設定的？** 例如傳給小明時加上「—— 來自 froglssh」。傳給您自己時是否省略？
4. **需要「重複提醒」嗎？** 例如「每個月 5 號提醒我繳卡費」、「每天早上八點提醒我吃藥」。（您原本沒提到；加上去不難，但會用掉較多每月 200 則的額度）
5. **要能用說的「取消／修改」提醒嗎？** 例如「把繳卡費的提醒改到十一點」。還是在畫面上按刪除就夠了？
6. **您的手機是 iPhone 還是 Android？** 這會影響我寫「加到主畫面」教學的截圖。
7. **登入方式**：用「一組密碼」登入可以嗎？（最簡單。進階選項是用手機的指紋／Face ID，但設定稍微複雜）
8. **AI 的聲音**：想要男聲、女聲，或是等做好後讓您試聽幾種再選？
9. **只提醒到 LINE 就好嗎？** 還是提醒時間到時，網頁本身也要跳出通知？
10. **提醒可以提早多久建立？** 例如「明年 3 月提醒我換駕照」這種很久以後的提醒，也需要支援嗎？（技術上可以，只是確認需求）
