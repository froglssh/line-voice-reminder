# 設定教學：讓提醒小幫手上線

> 這份教學只包含「**只有您本人能做**」的步驟，其他的程式部分我都已經完成。
> 全程大約 **30～40 分鐘**，建議用**電腦**操作（畫面比較大）。
> 每完成一個大步驟，跟我說一聲「第 X 步完成」，遇到卡關就把畫面截圖給我。

### ⚠️ 最重要的安全守則

在過程中您會拿到幾串「**金鑰**」（像密碼一樣的長串文字）。
- **絕對不要把金鑰貼到聊天室、Email 或 LINE**，只貼在教學指定的地方。
- 拿到金鑰後，可以先暫時貼在電腦的「記事本」裡，全部設定完再把記事本刪掉。

## 第 1 步：申請 LINE 官方帳號（10 分鐘）

這個帳號就是之後幫您傳提醒的「提醒小幫手」。

### 1-1 建立官方帳號
1. 打開 <https://entry.line.biz/start/tw/>，選 **「建立 LINE 官方帳號」**（免費）。
2. 用**您自己的 LINE 帳號**登入（手機 LINE 會跳出確認，按「允許」）。
3. 填寫資料：
   - **帳號名稱**：`line提醒小幫手`（這是家人看到的名字，之後可改。若 LINE 顯示名稱不能使用，可改成 `froglssh提醒小幫手`）
   - **Email**：您的 Email
   - **公司／店家名稱**：填「個人」即可
   - **業種**：選「個人」→「個人（其他）」
4. 按「確定」→「完成」。

### 1-2 開啟 Messaging API
1. 到 <https://manager.line.biz/>，點進剛建立的「line提醒小幫手」。
2. 點右上角 **「設定」**（齒輪圖示）。
3. 左邊選單點 **「Messaging API」** → 按 **「啟用 Messaging API」**。
4. 「服務提供者」選 **「建立新的服務提供者」**，名稱填 `froglssh`。
5. 隱私權政策、服務條款的網址**留空**，直接按「確定」。

### 1-3 關掉 LINE 內建的自動回覆（避免家人收到奇怪的罐頭訊息）
1. 還是在 <https://manager.line.biz/> 的「設定」頁面，左邊點 **「回應設定」**。
2. 設成這樣：
   - **聊天**：關閉
   - **加入好友的歡迎訊息**：關閉（小幫手會自己打招呼）
   - **Webhook**：**開啟** ✅
   - **自動回應訊息**：關閉

### 1-4 取得兩串 LINE 金鑰
1. 打開 <https://developers.line.biz/console/>，用同一個 LINE 帳號登入。
2. 點您建立的服務提供者（例如「froglssh」或「Papaya」）→ 點 **「line提醒小幫手」**。
3. 在 **「Basic settings」** 分頁往下捲，找到 **「Channel secret」**，按旁邊的複製 → 貼到記事本，標註 **「LINE_CHANNEL_SECRET」**。
4. 切到 **「Messaging API」** 分頁，捲到最下面 **「Channel access token (long-lived)」**，按 **「Issue」**，複製那一長串 → 貼到記事本，標註 **「LINE_CHANNEL_ACCESS_TOKEN」**。

✅ 第 1 步完成！跟我說一聲。（**不用**把金鑰給我）

## 第 2 步：申請 Cloudflare 並讓網站上線（15 分鐘）

Cloudflare 是放網站和「雲端小管家」的地方，24 小時不關機、免費。

### 2-1 註冊帳號
1. 打開 <https://dash.cloudflare.com/sign-up>，用 Email 註冊。
2. 到信箱收驗證信，點連結完成驗證。
3. 如果它問您要做什麼，選 **「Skip / 略過」** 就好，**不需要**購買網域或任何方案。

### 2-2 把程式接上 Cloudflare
> 開始前請先跟我確認：我會先把程式放到專案的主要版本（main）上，Cloudflare 才會抓到正確的版本。

1. 左邊選單點 **「Compute (Workers)」**（或「Workers & Pages」）→ 按 **「Create」**（建立）。
2. 選 **「Import a repository」**（匯入存放庫）。
3. 按 **「Connect GitHub」**，照畫面登入 GitHub，並允許 Cloudflare 讀取 `line-voice-reminder` 這個專案。
4. 選 **froglssh / line-voice-reminder**。
5. 設定頁面：
   - **Project name**：`line-voice-reminder`（一定要一模一樣）
   - 其他欄位**都不要改**
6. 按 **「Deploy」**，等 1～2 分鐘，出現 **「Success」** 就代表上線了。

### 2-3 設定密碼與 LINE 金鑰
1. 在 `line-voice-reminder` 頁面，點上方 **「Settings」**（設定）分頁。
2. 找到 **「Variables and Secrets」**（變數和秘密），按 **「+ Add」**。
3. 一次新增一個，**Type 都選「Secret」**：

| Variable name（名稱，要一模一樣） | Value（值） |
|---|---|
| `APP_PASSWORD` | 您想用的登入密碼（建議 12 個字以上，自己記得住的一句話也可以） |
| `LINE_CHANNEL_SECRET` | 記事本裡的 LINE_CHANNEL_SECRET |
| `LINE_CHANNEL_ACCESS_TOKEN` | 記事本裡的 LINE_CHANNEL_ACCESS_TOKEN |

4. 按 **「Deploy」**（部署）儲存。

### 2-4 找到您的網址
1. 在 `line-voice-reminder` 頁面的 **「Settings」** → **「Domains & Routes」**。
2. 會看到一個 `line-voice-reminder.frog-cbd.workers.dev` 的網址，這就是您的提醒小幫手網址！把它記下來。

## 第 3 步：把 LINE 和網站接起來（3 分鐘）

1. 回到 <https://developers.line.biz/console/> →「line提醒小幫手」→ **「Messaging API」** 分頁。
2. 找到 **「Webhook URL」**，按「Edit」，貼上：
   `https://line-voice-reminder.frog-cbd.workers.dev/line/webhook`
   （把 `line-voice-reminder.frog-cbd.workers.dev` 換成您在 2-4 看到的網址）
3. 按 **「Update」**，再按 **「Verify」**，出現 **「Success」** 就成功了。
4. 下方的 **「Use webhook」** 要是**開啟**的狀態。

## 第 4 步：第一次使用與測試（5 分鐘）

1. 用電腦打開您的網址，輸入 `APP_PASSWORD` 的密碼登入。
2. 點 **「聯絡人」** 分頁 → 用**手機 LINE** 掃描畫面上的 QR Code → 加入好友。
   - 您的 LINE 會收到小幫手的打招呼訊息。
3. 回到網頁，重新整理，聯絡人會出現您的 LINE 名稱：
   - 「稱呼」填 `froglssh`
   - 勾選 **「這是我自己」** → 按「儲存」。
4. 點 **「提醒」** 分頁 →「＋ 用打字新增提醒」：
   - 內容：`喝水`
   - 提醒誰：我
   - 時間：**現在時間加 2 分鐘**
   - 按「建立提醒」。
5. **把網頁關掉、電腦關機也沒關係**，2 分鐘內您的 LINE 應該會收到「⏰ 提醒：喝水」。
6. 再打開網頁，這筆提醒會顯示 **「已送出」**。

🎉 恭喜！提醒小幫手已經正式上線。

## 第 6 步（先準備，下一階段會用到）：Gemini 語音 AI 金鑰

1. 打開 <https://aistudio.google.com/apikey>，用 Google 帳號登入。

## 第 7 步：測試語音對話

做完第 6 步（設定 `GEMINI_API_KEY`）之後，**等 30 秒**再重新整理網站。

1. 按下綠色麥克風。第一次會問能不能使用麥克風，按 **「允許」**。
2. 幾秒內會聽到：「**嗨，froglssh，有什麼我可以幫忙的？**」，麥克風下方也會出現同樣的文字。
3. 請依序試試看這幾句：

| 您說 | AI 應該要… |
|---|---|
| 「兩分鐘後提醒我喝水」 | 念出時間請您確認 → 您說「對」→ 清單出現這筆 → 2 分鐘後 LINE 收到 |
| 「下週三早上十點提醒我去繳信用卡卡費」 | 念出正確日期（星期三）和 10:00 請您確認 |
| 「明天提醒我買牛奶」 | **反問您幾點**，不會自己亂猜 |
| 「提醒阿花去取貨」（阿花不是好友） | 告訴您阿花還沒加入，問要不要改成提醒自己 |
| AI 確認時您說「不對，改成下午三點」 | 用新的時間再確認一次 |
| 「我現在有哪些提醒？」 | 念出還沒送出的提醒 |
| 「把喝水的提醒取消」 | 確認後取消，清單上那筆消失 |

4. 說完了，**再按一次麥克風**就會結束對話。

**如果出現錯誤：**
- 「尚未設定 Gemini 金鑰」→ 第 6 步的名稱要是 `GEMINI_API_KEY`，而且要按「Deploy」。
- 「Gemini 金鑰不正確」→ 重新到 Google AI Studio 複製一次金鑰。
- 「沒有麥克風權限」→ iPhone：設定 → Safari → 麥克風 → 允許；電腦 Chrome：網址列左邊的圖示 → 麥克風 → 允許。
- 其他錯誤 → 把畫面截圖給我。

## 第 8 步：AI 圖片賀卡（OpenAI，需付費）

### 8-1 確認 OpenAI 帳戶有餘額
API 金鑰本身不等於免費額度，每張圖都會從 OpenAI 帳戶餘額扣款（每張約新台幣 0.3～6 元，重做也算一張）。
1. 打開 <https://platform.openai.com/settings/organization/billing/overview>，登入 OpenAI。
2. 看「**Credit balance**」（餘額）：
   - 大於 0 → 可以直接用。
   - 等於 0 → 按「**Add to credit balance**」，輸入金額（最少 5 美元），用信用卡付款。
3. **建議設定花費上限**：左邊選單「**Limits**」→「**Set a monthly budget**」填 `5`（美元），超過就會自動停用，不會多扣錢。
4. **不要**開啟「Auto recharge」（自動儲值）。

> 程式本身也有保護：每天最多做 20 張圖（可以請 Claude 調整）。

### 8-2 放入 OpenAI 金鑰
1. 到 <https://platform.openai.com/api-keys>，可用現有的金鑰，或按「**Create new secret key**」建立一把新的並複製。
2. Cloudflare →「line-voice-reminder」→「Settings」→「Variables and Secrets」→「+ Add」：
   - Type：**Secret**
   - 名稱：`OPENAI_API_KEY`
   - 值：剛剛的金鑰
3. 按「**Deploy**」。

### 8-3 測試
對麥克風說：「**幫我做一張中秋節賀卡，一分鐘後傳給我**」
1. AI 說「我來畫，請稍等」→ 畫面出現「AI 畫圖中…」。
2. 十幾秒後圖片出現在麥克風下方 → 可以說「月亮再大一點」「換成水彩風格」請它重做。
3. 說「就用這張」→ AI 幫您擬祝福文字、念出時間和對象請您確認 → 說「對」。
4. 清單出現一筆有縮圖的「等待中」提醒，時間到 LINE 會先收到圖片、再收到祝福文字。
5. 想馬上看效果：按提醒右邊的「**➤**」（現在送出）。

## 常見問題

**Q：家人要怎麼加入？**
網頁「聯絡人」分頁有「複製邀請連結」（手機上還有「分享給家人」），傳給家人點開加好友即可。加入後在網頁上幫他取個稱呼（例如「小明」）。

**Q：我想測試「一週後自動刪除」，但不想等 7 天？**
Cloudflare →「Settings」→「Variables and Secrets」，把 `RETENTION_MINUTES` 暫時改成 `3`，已送出的提醒 3 分鐘後就會消失。測完請改回 `10080`。

**Q：忘記登入密碼？**
到 Cloudflare 把 `APP_PASSWORD` 改成新的密碼即可。

**Q：密碼輸錯太多次被鎖住？**
等 15 分鐘就會自動解鎖。
